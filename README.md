# Koko Kits

Koko Kits is a category-based Korean conversation kit site built with Next.js.

## Development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Current MVP

- `/en`
- `/en/kits`
- `/en/kits/travel/cafe-ordering`
- `/en/kits/travel/cafe-ordering/quiz`
- `/download/travel-cafe-ordering-pdf`
- `/go/travel-cafe-ordering-koko`
